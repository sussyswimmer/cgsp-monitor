Keeping it running

      
    
        
  • Leave this tab open in Chrome or Edge on this PC, as the front tab of its own window (minimising the window is fine), or pinned (right-click the tab, Pin). A tab left behind other tabs can be put to sleep.
    • 
        
  • Memory Saver: Chrome’s Memory Saver puts background tabs to sleep, and a sleeping tab cannot start the run. Add this site under Settings → Performance → Always keep these sites active.
    • 
        
  • Permission: the first time, Chrome asks to let this site reach apps on this device. Choose Allow, or the page cannot start the run.
    • 
        
  • Sleep: the helper wakes a sleeping computer just before the send time, if Windows allows wake timers. A computer that is shut down, or that does not wake, sends nothing that morning.
    • 
        
  • Late: opened up to 90 minutes after the send time, the page still starts the run. Later than that, the morning is skipped.
